# Stream 2.2: extract-core

Release-notes fragment for stream 4.2 to assemble. Changes
`py_apple_books/utils.py` only: no new public API, and no change to any
returned text.

## CHANGELOG

### Changed

- **Faster chapter text.** The HTML-to-text step behind `get_chapter`,
  chapter content and annotation context is now one linear pass over each
  chapter file. It no longer modifies the parsed document (1.10 inserted
  line breaks into it before extracting text), and its time no longer grows
  with the square of the number of paragraphs in a file: a chapter file with
  10,000 paragraphs now takes a fraction of a second instead of several
  seconds. The returned text is unchanged, character for character; the
  test suite compares it with the 1.10 code on many thousands of generated
  documents, on the oldest and the newest supported beautifulsoup4.
