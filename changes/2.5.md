# Stream 2.5: engagement

Release-notes fragment for stream 4.2 to assemble. New methods for
resurfacing highlights, date bounds on two existing methods, and a
per-book breakdown of highlights whose book was removed. Every new
method reads the Apple Books databases (and, for reading goals,
Books' preferences file); no book file is opened.
Existing calls return what they did in 1.10.

## CHANGELOG

### Added

- `get_underlines(limit=None, order_by='-creation_date', *, offset=None,
  include_deleted=False)`: your underlines, newest first. Bookmarks and
  the reading-position row are never included. On a Books version
  without the underline flag, highlights without a color are returned
  instead.
- `sample_highlights(limit=5, *, offset=None, on=None, seed=None,
  book_id=None, after=None, before=None, exclude_ids=(),
  exclude_uuids=(), exclude_short=True, include_orphans=False)`: a
  varied, repeatable sample of your highlights for a day. The same day
  and seed give the same picks on every platform; a new day gives new
  ones. Highlights with a note count twice, and without `book_id` the
  picks go round-robin across books, so the first ones come from
  different books. Words and short phrases are left out by default.
  Nothing is stored: pass what you have already shown in `exclude_ids`
  or `exclude_uuids` (None for either excludes nothing). The algorithm
  is named by
  `py_apple_books.engagement.SAMPLE_ALGORITHM` (`'pab-sample-v1'`).
- `get_highlights_on_this_day(on=None, limit=None,
  order_by='-creation_date', *, offset=None, include_deleted=False,
  include_orphans=True)`: highlights and notes made on this calendar day
  in earlier years, newest first. Counted and paged in SQL.
- `get_finished_books(..., *, finished_after=None, finished_before=None)`:
  keep the books whose finish date is in a window ("what did I finish
  this year"). Books records the date a book was marked as finished, so
  books marked in bulk share one.
- `get_annotations_by_date_range` accepts dates as well as datetimes: a
  date covers that whole local day (it raised `AttributeError` before).
- `LibraryStats.orphan_assets`: `(asset id, count)` for every asset id
  that annotations name and no book has, most annotations first. Its
  counts add up to `orphan_annotations`.
- New module `py_apple_books.engagement` (`SAMPLE_ALGORITHM`), the home
  of the engagement types.
- `get_vocabulary(limit=None, order_by='-last_highlighted', *,
  offset=None, book_id=None, after=None, before=None,
  underline_only=False)`: the words and short phrases you highlighted,
  grouped across books ("Ephemeral," and "ephemeral" are one entry; no
  stemming). Each `py_apple_books.engagement.VocabularyEntry` has the
  `term`, its highlights (newest first), `count`, `notes`,
  `first_highlighted`/`last_highlighted`, `asset_ids`, and `context`: a
  sentence it was used in, from the text Books keeps around the
  highlight. Orders: `last_highlighted`, `first_highlighted`, `term`,
  `count`, each with or without `-`. Returns a list.
- `get_highlight_activity(*, after=None, before=None, book_id=None,
  granularity='month')`: how much you highlighted in a window, as a
  `py_apple_books.engagement.HighlightActivity`: highlights, notes,
  active days, books (removed ones counted apart), first and last
  highlight, per-book counts, and `ActivityPeriod`s by day, ISO week,
  month or year.
- `get_highlight_streaks(*, on=None)`: runs of consecutive days with a
  highlight (`HighlightStreaks`: current and longest run, last active
  day, active days). Both measure highlighting, not reading time, which
  Books doesn't record in a form the library can read.
- `get_reading_goals(*, prefs_path=None)`: Books' reading goals as it
  last saved them, as a `py_apple_books.engagement.ReadingGoals`: the
  yearly books goal, the daily reading goal (`daily_goal_seconds`,
  `daily_goal_minutes`), Books' own current streak, its list of books
  finished towards the goal (`finished_assets`,
  `books_finished_in(year)`) and when the file was written. Read from
  Books' preferences file next to the library, a new data source for
  the library: read-only, in-process, a regular local file of at most
  8 MiB (a path in an iCloud Drive or other cloud folder, by name or
  through a symlinked folder, a file that is not downloaded, a link or
  a special file is refused),
  and only these four settings are kept. Returns None when the file is
  missing or can't be read safely; never raises for that.

### Compatibility notes

- New methods take dates by one rule: `after`/`before` (and
  `finished_after`/`finished_before`) are inclusive; a datetime is an
  instant (naive means local time), a date covers that whole local day.
  `on` names a local calendar day; its time of day is ignored. Any other
  type raises `InvalidArgumentError`.
- New methods refuse a `limit` below 1 (or a bool) with
  `InvalidArgumentError`; None means no limit. The existing methods keep
  their deprecated "`limit <= 0` means all" behaviour.
- `LibraryStats` has a new last field with a default, so `repr()` and
  `==` include it; positional construction with the seven earlier
  arguments still works.
- Books' own list of finished books (`ReadingGoals.finished_assets`)
  and the library's (`get_finished_books`) are separate records and can
  differ; both are returned as they are.
- `sample_highlights` with `exclude_short` follows the running Python's
  Unicode database, so after a Python upgrade a highlight made of newly
  assigned characters can be classified differently.

- "Available Functions": add a "v1.11.0+ engagement" group with the
  new methods and their one-line descriptions above, and note the new
  `get_finished_books` and `get_annotations_by_date_range` arguments.
  `get_vocabulary` returns a list, like `get_library_stats` (for a

- "Default orders" table: `get_underlines` and
  `get_highlights_on_this_day` newest first; `sample_highlights` in
  sample order (`SAMPLE_ALGORITHM`); `get_vocabulary` most recently
  highlighted first (`'-last_highlighted'`).
- A "Dates" paragraph next to "Pagination and counting": the rule in the
  compatibility notes above.
- `LibraryStats`: describe `orphan_assets`.
- A "What can and can't be derived" note: highlight activity and
  streaks count highlights; reading minutes, pages read per day and
  Books' streak history are not available to the library; reading goals
  come from Books' preferences file as Books last saved it.
- An "Engagement" section: what the sample is (resurfacing, not spaced
  repetition: no state is kept), the note weighting and round-robin
  across books, the `exclude_*` arguments for callers that keep their
  own "already shown" list, and that PDF highlights are not in the
  annotation database and so are not sampled.
