# Stream 1.4: testing-kit

Release-notes fragment for stream 4.2 to assemble. Testing package only
(`py_apple_books.testing`, provisional API): no change to the library's
API or output. Still standard library only, and still loads on its own.

## CHANGELOG

### Added

- **`write_epub_bundle(dest, files, toc=(), ...)`** writes an unzipped
  EPUB 3 bundle in the shapes real books come in, byte for byte the
  same on every run: the package document in any folder (or the bundle
  root), files in sub-folders, a nav document and an NCX, either one,
  an NCX the spine doesn't name, or no table of contents at all; nested
  entries with fragments and headings without links; the nav document
  in the spine; non-linear, repeated or malformed spine entries
  (`spine_xml=`); other media types (HTML, SVG, raw bytes); stylesheets,
  images and other manifest-only items; guide references and nav
  landmarks; and package metadata left out or added as raw XML.
  `write_epub` is unchanged (its output is pinned, as the MCP
  compatibility goldens depend on it).
- **`FixtureLibrary` helpers** for the data 1.11 reads:
  - `add_book(finished_date=, last_engaged=)`: when a book was finished
    and last engaged with.
  - `add_annotation(user_data=, position_fraction=, furthest_fraction=)`
    and `page_location_blob(page_offset, ordinal=0)`: Books' own
    position record on a bookmark row (a PDF's page, or an EPUB
    bookmark's spine item) and the reading and furthest fractions, which
    Books stores as text (a str is written verbatim, to test bad
    values).
  - `add_series(title, volumes, *, ordered=True, store_id=None)`: a
    Store series container and its volumes, linked as Books links them.
  - `prefs_path` and `write_prefs(...)`: a synthetic Books preferences
    plist with the reading-goal, streak and finished-books keys,
    including the year-0 date (`YEAR_ZERO`) that stops plain `plistlib`
    from reading Books' own file; dates can be given as raw Core Data
    seconds to write unreadable ones on purpose.
  - `book_info_dir` and `add_book_info_cache(rows, ...)`: a Books
    per-book info cache built from the committed schema, with
    `columns=` to drop columns and any SQLite journal mode (WAL, as
    Books uses, closed cleanly by default).
- Rows built with the default arguments are exactly the rows 1.10's
  helpers wrote, so existing fixtures and stores from older Books
  versions keep working.
